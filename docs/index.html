SpeakCoach

SpeakCoach este o aplicație pentru analiza prezentărilor orale. Utilizatorul încarcă slide-urile și o înregistrare a prezentării, iar aplicația oferă feedback despre ritm, pauze, cuvinte de umplutură și acoperirea ideilor din slide-uri.

Proiect de licență, Universitatea „Lucian Blaga” din Sibiu.
